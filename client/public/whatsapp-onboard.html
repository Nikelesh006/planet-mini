WhatsApp Cloud API • Coexistence

Connect Planet Mini WhatsApp

Link your existing WhatsApp Business mobile number to Cloud API so you can chat from your phone while your server sends automated order updates.

During the popup:
  1. Select your Planet Mini Meta Business Account.
  2. Enter your WhatsApp Business mobile number.
  3. Select "Use with WhatsApp Business App and Cloud API" (Coexistence).
  4. Enter the 6-digit OTP code to verify.
